# uni_school - Платформа онлайн-обучения

## Описание проекта

uni_school — это веб-приложение для управления онлайн-курсами в университете, реализованное с использованием Django. Проект предоставляет полный функционал для регистрации пользователей, оплаты курсов, доступа к учебным материалам и управления фоновыми процессами через Celery.

Разработано как образовательная платформа с акцентом на надежность, масштабируемость и удобство использования для студентов, преподавателей и администраторов.

## Функционал платформы

### Основные страницы и возможности:
- **Регистрация и авторизация**: Поддержка разных ролей пользователей
- **Личные кабинеты**: Для студентов, модераторов и администраторов
- **Управление курсами**: Просмотр, запись на курсы, доступ к материалам
- **Система оплаты**: Обработка платежей и обновление статуса оплаты
- **Уведомления**: Автоматические уведомления пользователям
- **Администрирование**: Полный контроль над контентом и пользователями

### Роли пользователей:
- **Администратор**: Полный доступ к системе, управление пользователями и курсами
- **Модератор**: Управление контентом, проверка материалов
- **Пользователь (студент)**: Доступ к курсам, оплата, просмотр материалов

## Настройка переменных окружения

### Создайте файл `.env`
1. Скопируйте шаблон:
```bash
cp .env.sample .env
```

2. Заполните необходимые переменные в файле `.env`:

### База данных
```
POSTGRES_DB=uni_school_db
POSTGRES_USER=postgres
POSTGRES_PASSWORD=your_secure_password
```

### Django
```
SECRET_KEY=your_strong_secret_key
DEBUG=False
```

### Email (на пример Yandex SMTP)
```
EMAIL_HOST=smtp.yandex.ru
EMAIL_PORT=465
EMAIL_USE_TLS=False
EMAIL_USE_SSL=True
EMAIL_HOST_USER=your_email@yandex.ru
EMAIL_HOST_PASSWORD=your_app_password
DEFAULT_FROM_EMAIL=your_email@yandex.ru
```

### Celery (в settings.py)
```
CELERY_BROKER_URL=redis://redis:6379/0
CELERY_RESULT_BACKEND=redis://redis:6379/0
```

> Сохраните файл `.env` в корне проекта.

## Запуск приложения

### 1. Сборка и запуск
```bash
docker compose up --build    # Сборка и запуск
```

```bash
docker compose up -d         # Запуск в фоновом режиме
```

- Приложение будет доступно по адресу: http://localhost:8000
- Админка доступна по адресу: http://localhost:8000/admin
- Документация в формате Sphinx доступна по адресу: http://localhost:8000/api/docs
- Swagger доступен по адресу: http://localhost:8000/api/swagger

### 2. Остановка и очистка
```bash
docker-compose down -v       # Остановка и очистка контейнеров и томов
```

```bash
docker compose down          # Простая остановка
```

## Архитектура сервисов (docker-compose.yml)

| Сервис   | Назначение                         |
|----------|------------------------------------|
| `db`     | PostgreSQL 16.0, хранение данных   |
| `redis`  | Хранилище для Celery и кэширования |
| `web`    | Django-сервер (runserver)          |
| `celery` | Воркер для фоновых задач           |
| `beat`   | Планировщик периодических задач    |

## Celery и фоновые задачи

### Сервис `celery`

- Запускает воркер: `celery -A uni_school worker -l info`
- Обрабатывает:
  - Системные оповещения
  - Отправку email-уведомлений
  - Обновление статуса оплаты
  - Другие асинхронные операции

### Сервис `beat`

- Планировщик задач: `celery -A uni_school beat`
- Использует `django-celery-beat` для хранения расписания в БД
- Периодические задачи:
  - Ежедневная проверка статуса оплаты
  - Генерация отчетов
  - Отправка напоминаний пользователям
